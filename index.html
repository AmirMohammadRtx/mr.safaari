آخرین بروزرسانی: امروز

۱) راه‌اندازی و نصب اولیه

مقدمات فنی برای شروع پروژه

  • نصب وردپرس روی هاست
  • ساخت دیتابیس و تنظیمات اولیه
  • انتخاب و نصب قالب مناسب

۲) طراحی و ساختار صفحات

طراحی UI/UX صفحات کلیدی

  • طراحی صفحه اصلی
  • صفحات درباره ما، تماس، خدمات
  • لندینگ پیج و صفحات محصول

۳) نصب و تنظیم افزونه‌ها

افزونه‌های ضروری و پیکربندی

  • افزونه‌های امنیت و بکاپ
  • افزونه‌های سئو و بهینه‌سازی سرعت
  • فرم‌ساز و ادوات فروشگاه در صورت نیاز

۴) سفارشی‌سازی قالب

تنظیمات ظاهری و CSS جزئی

  • رنگ‌بندی و تایپوگرافی
  • هدر، فوتر و منوها
  • تغییرات CSS بدون برنامه‌نویسی سنگین

۵) بهینه‌سازی سرعت

عملکرد و لود سریع صفحات

  • بهینه‌سازی تصاویر
  • فعال‌سازی کش و فشرده‌سازی
  • تنظیمات مرتبط با Core Web Vitals

۶) سئو فنی

پایه‌های SEO که باید انجام شود

  • تنظیم عنوان‌ها و توضیحات متا
  • ایجاد نقشهٔ سایت و robots.txt
  • ساختار URL و headingها

۷) امنیت و نگهداری

پشتیبانی فنی پایه

  • نصب افزونه امنیت
  • بکاپ‌گیری دوره‌ای
  • بروزرسانی هسته و افزونه‌ها

۸) آموزش و تحویل

تحویل کامل و انتقال دانش به کارفرما

  • تحویل اطلاعات ورود
  • آموزش کار با پنل و مدیریت محتوا
  • ارسال ویدئو یا فایل راهنما (در صورت توافق)

موارد خارج از تعهد طراح

مواردی که باید در قرارداد جدا قید شوند

  • تولید محتوا (متن، تصویر، ویدئو)
  • سئوی تخصصی و لینک‌سازی
  • طراحی لوگو و هویت بصری
  • برنامه‌نویسی اختصاصی سنگین
  • مدیریت روزانه فروشگاه (مگر قرارداد جدا)
